## 结论

GUI 与默认回测现在使用完全相同的 50 个 Binance USDT-M 合约。
当前不活跃的 `TON/USDT:USDT` 已由 `SEI/USDT:USDT` 替换；截至本次
核验，50 个合约均为正常交易状态，且3个月与6个月所需历史数据及
窗口前 600 根 1h 预热K线完整。
Breakout v10F 与 Grid v7 的策略代码未修改。

  横截面行情宽度和候选排名，替换一个币仍会改变其他币的信号及共享复利路径，
  因此结果不能用删减 TON 成交简单推算。

## 回测口径

- 3个月：2026-04-19 至 2026-07-19
- 6个月：2026-01-19 至 2026-07-19
- 初始资金 200U，共享复利，最多两仓
- 1h 收盘信号，1m 明细执行
- 逐仓合约，单边费用/滑点代理 0.08%
- 无缓存，启用回测保护，逐笔成交导出

旧币池配置保存在 `config.backtest.legacy-ton50.json`，默认
`config.backtest.json` 与 `config.gui.json` 则固定为当前 Active 50。
