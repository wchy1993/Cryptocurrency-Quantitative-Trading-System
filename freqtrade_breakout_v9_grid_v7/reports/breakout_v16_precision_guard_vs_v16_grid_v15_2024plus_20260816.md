# V16 新精度止损 + Grid V15：2024 至今对照回测

日期：2026-08-16

## 结论

新精度止损版不是“总收益全面更高”，而是一次比较成功的风险收益交换：完整区间净利润比旧 V16 + Grid V15 少 2.41%，但 PF 提高 8.58%，胜率提高 0.53 个百分点，钱包历史峰值最深水下降低 2.46 个百分点，日钱包 Sharpe 提高 22.38%，最大单笔亏损也明显缩小。

因此，如果目标是实盘执行正确性、避免价格精度向风险内侧取整和改善风险调整后表现，应继续使用新精度版；如果只追求这条无限复利回测的最高最终余额，旧版仍高约 2.48%。不建议为了这 2.41% 的数学回测利润退回已知存在精度缺陷的旧止损。

不过，新版仍有两个不能忽略的问题：严格钱包最深水下仍为 25.82%，没有降到 15% 以下；最大一次水下恢复时间从旧版约 63 天拉长到约 223 天。因此它降低了“跌多深”，却增加了“横多久”，不能称为全面支配旧版。

Breakout 少 4 单、利润少 3.45%，但 PF 提高 9.44%、胜率提高 2.68 个百分点。Grid 代码没有改变，但共享余额、占仓时间和后续信号路径发生联动，因此少 12 单，利润反而增加 7.52%、PF 提高 11.13%。不能把它解读成 Grid 逻辑本身被优化。

方向上，新版多单 PF 从 15.363 降到 14.348，空单 PF 从 4.469 提高到 5.103。整体 PF 改善主要来自空单侧，符合该组合空单占比较高的结构。

## 新止损实际改变了什么

- 530 笔新交易中，有 523 笔能按币种、开仓时间、入场标签和方向与旧版一一对齐。
- 旧版独有 23 笔，新版独有 7 笔；这是退出时间、共享槽位和复利余额变化造成的后续连锁。
- 523 个共同开仓中，355 笔退出时间和退出原因完全相同，168 笔发生变化。
- 新版有 57 笔 `bo_precision_soft_1m`，全部对应旧版的初始 `stop_loss`。这 57 笔合计仍亏损，但按逐笔收益率求和比旧版略好约 0.105。
- 另有 7 笔旧版初始止损交易在新版延续到 `bo_v9_time_stop`，其中 6 笔真正由亏转盈。代表样本包括 2024-02-09 的 1000BONK（约 -12.96% → +186.39%）和 2024-01-22 的 ETH（约 -7.87% → +57.76%）。
- 28 笔旧版初始止损交易在新版转为后续 `trailing_stop_loss`；这些交易最终仍亏损，但逐笔收益率总和较旧版改善约 0.632。
- 结果中的 `stop_loss` 退出数从 168 降到 73；`trailing_stop_loss` 从 60 增到 96，time-stop 从 63 增到 70。

说明改进不是来自所有软止损交易本身赚钱，而是少量被正确保留下来的趋势交易贡献了明显凸性，同时风险缩仓减少了后期损失规模。

## 采用建议

1. 实盘继续使用新精度止损版，不退回旧精度。风险外侧取整和真实止损距离缩仓属于执行正确性修复，不应仅因数学回测少 2.41% 就撤销。
2. 不把本结果解读为回撤目标已经完成。25.82% 仍明显高于 15%，且 223 天恢复期对实盘体验不友好。
3. 如果继续研究，下一步应只针对“资金曲线长期停滞”和“粗 tick/ATR 币种的保护成本”做独立候选，不修改 V16 入场和 Grid V15 逻辑，并保留当前版本作为冻结对照。
4. GUI 和正在运行的实盘进程本轮没有被修改或重启。

## 回测口径与限制

- 当前固定 Active50、Binance USDT 永续、逐仓、200U 初始资金、无限复利、共享最多 2 个仓位。
- 1h 信号、V16 的 15m 管理、1m detail 柱内执行；缓存禁用，命令行启用 protections，但策略没有额外 protection handler。
- 费用、滑点代理和资金费沿用冻结旧基线口径。
- 当前固定 50 币是用现有研究池回看历史，仍存在幸存者偏差和币池选择前视，不是严格 point-in-time 动态币池。
- 无限复利后期最大 stake 达到数百万 U，1m OHLCV 无盘口深度、排队、延迟和真实冲击；绝对 U 结果不可直接外推实盘容量。
